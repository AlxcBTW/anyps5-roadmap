About this data

Generated data, community prototype, not official. This page is built by a script from public GitHub issues and PRs of boykopovar/AnyPS5 plus a small curated file. The maintainers have not reviewed it. Mined entries can be wrong; check the linked source before you act on one.

Issues and PRs come from the GitHub API: all open ones and those closed in the last 60 days. Title IDs, names, stages and error signatures are mined from issue and PR text. GitHub “blocked by” links are used where they exist. Entries marked curated come from data/blockers.json and win over mined ones.

  • roadmap.json: everything on this page, with a schema version
  • ROADMAP.md: the same as Markdown
  • llms.txt: a guide to these files for AI agents
  • AGENTS.md: how to curate blockers.json
Known gaps in the mining
  • Title names, engines and stages are mined with keyword rules per line; negation and context are handled only roughly.
  • Mined chain order is a heuristic: the latest recorded stop first, then issues by creation date.
  • PR comments and review threads are not read; only PR titles and bodies are.
  • Titles without a PPSA ID (some homebrew) appear only when curated.
  • Discord reports are invisible unless someone copies them into GitHub or the curated file.
  • Signatures are matched by prefix after hex addresses and long numbers are masked; reworded messages split into separate keys.
  • PM4 status reads Pm4::UnsupportedReason(); a packet can pass that check and still be emulated partially.
